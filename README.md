⚔️ Adventurers Guild - D&D Web Portal

A medieval fantasy-themed web landing page inspired by Dungeons & Dragons (D&D) lore. Built as a web development project focusing on clean HTML5 semantic structure and CSS3 Flexbox layout management
## 🛡️ Features

- **Fantasy Visual Theme**: Dark mode obsidian aesthetics (`#0f0e13`) paired with wizardly gold accents (`#c89d36`).
- **Flexible Layout**: Fully structured using **CSS Flexbox** for navigation, grid highlights, client rosters, and testimonial cards.
- **Lore-Accurate Content**: Customized content featuring D&D races, classes, dragons, and guild recruitment lore.
- **Modular Sections**:
  - 🏰 **Header & Guild Navigation**
  - 📜 **Main Quest Banner & Highlights**
  - 🗡️ **Adventurer Recruitment Section**
  - 🛡️ **Guild Client Roster**
  - 🐉 **Legendary Testimonials**
  - ✉️ **Guild Scroll Newsletter & Footer**

---

## 🧰 Tech Stack

- **HTML5**: Semantic tags structure (`header`, `nav`, `div` containers).
- **CSS3**: Custom styling, Flexbox layout, dark theme aesthetics.
- **VS Code**: Core IDE for layout module development.
